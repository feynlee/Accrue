# Realistic body pipeline (proof of concept)

Bakes an exercise from a few key poses into a skinned GLB with an anatomical
X-ray layer (shoulder blades, collarbones, arm bones, ribs, spine).

```
python -m venv .venv && .venv/bin/pip install bpy numpy   # Blender as a module
git clone https://github.com/makehumancommunity/mpfb2      # CC0 body, rig, weights
MPFB_DATA=mpfb2/src/mpfb/data .venv/bin/python pipeline/make.py \
    exercises/dumbbell-seated-shoulder-press.json out/press.glb
python3 viewer/build.py out/press.glb exercises/dumbbell-seated-shoulder-press.json press.html
```

- `pipeline/mhbody.py` loads the MakeHuman base mesh, applies the body-shape
  targets, and places the MakeHuman "default" rig and its skin weights.
- `pipeline/pose.py` turns anatomical numbers into bone transforms. The
  shoulder is collarbone (sternoclavicular joint) → shoulder blade (rides on
  the collarbone at the acromioclavicular joint) → humerus (carried by the
  glenoid). Arm elevation drives the girdle with scapulohumeral rhythm after
  Ludewig et al. 2009; any key pose can override `upRot`, `tilt`, `ir`,
  `clavElev`, `clavRetr`.
- `pipeline/skeleton.py` builds the shoulder-blade landmarks from the body
  surface, moves the skin over each blade onto a new `scapula` bone, paints the
  muscle masks, and makes the X-ray bone meshes.
- `pipeline/make.py` bakes every frame and writes the GLB plus a
  `.report.json` of joint angles per frame.

## Key pose format

```json
{"t": 0.45, "phase": "Top", "pose": {
  "arms": {"elev": 166, "plane": 32, "faDir": [0.06, 1, -0.16], "palm": [1, 0, -0.2]},
  "spine": {"thoracic": -4}}}
```

`elev` is thoracohumeral elevation, `plane` the plane of elevation (0 = out to
the side, 90 = straight forward). Vectors are in the ISB thorax frame of the
right arm (x forward, y up, z out to the side); the left arm is mirrored unless
`armL` is given.

## Sources

The body mesh, rig and weights come from MakeHuman via MPFB2, released CC0.
All other geometry is generated by these scripts. No Gym visual or openGym
media is used.
